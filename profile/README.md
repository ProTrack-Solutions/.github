## 🧩 Produtos e serviços

### ProTrack Gerencial
ERP em nuvem, multi-tenant, para o varejo de pequeno e médio porte.

- **Vendas e PDV**: vendas, caixa, devoluções e histórico
- **Estoque e compras**: produtos, categorias, fornecedores, código de barras e etiquetas
- **Clientes**: cadastro, perfil e vendas a prazo
- **Financeiro**: contas a pagar e a receber, fluxo de caixa e dashboard
- **Relatórios**: exportação em PDF e Excel
- **Cobrança via WhatsApp**: lembretes automáticos de vendas vencidas pela API oficial da Meta
- **Controle de acesso**: usuários, perfis e permissões por departamento
- **Assinatura online**: planos com teste grátis de 7 dias e demonstração aberta

### ProTrack Fiscal *(em breve)*
API de emissão de **NF-e e NFC-e**, integrada ao Gerencial e também oferecida como produto independente. Vem com portal web para emissão unitária, consulta de notas emitidas, parâmetros do emitente, API keys e webhooks.

### Desenvolvimento sob medida
- **Sistemas personalizados** para os processos específicos de cada negócio
- **Sites e landing pages** rápidos, modernos e otimizados para conversão
- **Aplicativos mobile** para Android e iOS
